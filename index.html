第一步：下載完整專案檔案

點擊下方按鈕即可自動將本系統打包為包含 index.html 與 README.md 說明檔的 .zip 壓縮檔；或直接單獨下載 index.html。

第二步：3 分鐘上傳到 GitHub 並變成專屬網頁 App

1. 建立新的 GitHub 專案庫 (Repository)

登入 GitHub 官網，點擊右上角的 「＋」➔「New repository」。
・在 Repository name 輸入名稱（例如：classroom-counseling-app）。
・確認選擇 Public（公開），勾選 Add a README file，然後拉到最下方點擊綠色的 「Create repository」。

2. 上傳解壓縮後的 index.html

・將剛剛下載的 index.html.zip 解壓縮，取出裡面的 index.html（重要：上傳到 GitHub 時請上傳解壓縮後的 index.html，這樣才能直接當作網頁開啟）。
・在您的 GitHub 專案頁面中，點擊 「Add file」➔「Upload files」。
・把 index.html 拖曳進網頁中央，接著點擊下方的綠色按鈕 「Commit changes」 完成上傳。

3. 開啟 GitHub Pages（產生手機/平板都能用的網址）

・點擊專案上方的 「Settings」（齒輪設定），再點選左側選單的 「Pages」。
・在 Branch（分支） 下拉選單中，將 None 改為 main（或 master），旁邊維持 /(root)，點擊 「Save」。
・等待約 1～2 分鐘並重新整理頁面，上方就會出現您的專屬網址：
https://您的帳號.github.io/classroom-counseling-app/
